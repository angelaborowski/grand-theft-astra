# Winter sky

`snow_field_puresky_2k.hdr` is the unmodified 2048-pixel Radiance HDR source from Poly Haven, used locally for both the background and physically based material environment. It is approximately 4 MB; there are no runtime network dependencies or per-frame reflection captures. The original HDR remains editable.

- Asset: https://polyhaven.com/a/snow_field_puresky
- Download: https://dl.polyhaven.org/file/ph-assets/HDRIs/hdr/2k/snow_field_puresky_2k.hdr
- Artists: Sergej Majboroda (original), Jarod Guest (sky edits).
- License: CC0, https://polyhaven.com/license and https://creativecommons.org/publicdomain/zero/1.0/
- Retrieved: 2026-09-10.

This is a photographic winter sky reference, not a verified Moscow capture. Rotation, exposure, and fill are editable in `scene-lighting.tsx`. No generated media was used.
